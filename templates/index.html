Common Issues & Solutions

Batch Processor Service Not Running

The Go batch processor service must be running separately.

cd batch-processor && go run main.go
Folder Path Issues

Make sure the folder path:

  • Is an absolute path
  • Exists on the server (not just on your local machine)
  • Has proper read/write permissions
  • Contains video files (.mp4, .mov, .avi, .mkv)
Too Many Files

The batch processor has a maximum limit of 15 video files per folder.
